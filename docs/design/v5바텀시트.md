# v5 휴대폰 바텀시트 · 데스크톱 고정 패널 (2026-11-03)

실사용 피드백: "매물 타입 카드를 눌러도 위쪽 평면도만 바뀌어서 모르겠다." 백업: `index_v4_backup.html`.

- `history.scrollRestoration = 'manual'`: 뒤로 가기로 시트를 닫을 때 브라우저가 스크롤을 덮어쓰지 않게 한다(화면 전환 스크롤은 `route()`가 직접).
- 시트 올라오기: `hidden` 해제 → 강제 레이아웃(`offsetHeight`) → `.open` 클래스. rAF 두 번 기다리던 방식은 프레임이 늦는 환경에서 시트가 늦게 떴다.
- 시트가 연 채로 화면이 768px 이상이 되면 닫는다. 포커스는 시트 안에서만 돈다.
- "45A를 눌렀는데 59C" 제보: 코드상 선택·패널·시트가 같은 값을 읽고, 390/1280에서 모든 카드 일치 검사 0건 불일치 → 휴대폰에서 패널이 목록 위에 있어 바뀐 걸 못 본 배치 문제로 판단, 시트로 해소.
