# 전세 → 월세 환산 · 관리비 규칙 읽기 (v36, 2026-11-26)

사용자 피드백 2건: 숫자만 적힌 관리비를 못 읽음 / 전세 매물을 월세 매물과 같은 기준으로 보고 싶음.

## 전세 → 월세 환산

```mermaid
flowchart TD
  A[매물] --> M[실제 월 부담 costParts — 바뀌지 않음]
  A --> C{거래 유형}
  C -- 매매 --> N[환산 없음 conv = null]
  C -- 월세·전세 --> V["환산 월 부담 conv = 월세(전세 0) + 보증금 × 전환율 ÷ 12 + 관리비(미확인 0)"]
  A --> J{전세?}
  J -- 예 --> S["카드·한눈에 비교: '전세 → 월세 환산 월 ○만원' = 전세금 × 전환율 ÷ 12<br/>자세히 보기: 계산식 (참고용 · 실제 월 부담과 별개)"]
  V --> R{설정 '순위에 환산값 쓰기' (기본 꺼짐)}
  R -- 꺼짐 --> P1[가격 점수 = 실제 월 부담]
  R -- 켜짐 --> P2[가격 점수 = conv · 매매는 실제 월 부담]
```

- 설정: `settings.convRate` (연 %, 기본 4.5) · `settings.convRank` (기본 false). 예전 데이터는 migrate 에서 기본값.
- 예산 상한·지금 집 비교·동점 정렬은 계속 실제 월 부담.
- 자체검사: 전세 2억 4.5% → 75 · 6% → 100 · 월세 1000/60·관리비 8·4.5% → 71.75 · 매매 null.

## 관리비 규칙 읽기

`관리(비)? [별도] [:] 숫자 [만[원]]` — '만' 없는 숫자는 만원. 숫자 뒤에 원·천·층·㎡·%·범위(~)가 오면 읽지 않고 미확인(null) 유지.
Worker 결과와 합칠 때 `{...규칙, ...Worker}` 라서 Worker 가 관리비를 비우면 규칙 값이 남는다.
검사: index.html selfTest + `scripts/verify/ai_check.py` (규칙 경로 · Worker 가 null 로 보낸 경로).
