# v32 매물 지도 모아 보기 (2026-11-13)

리포트 > 입지 장. 청약 체크의 공고·단지 지도와 같은 방식(멀리 = 구별 개수, 가까이 = 핀). 계산·점수는 그대로.

```mermaid
flowchart TD
  A[입지 장 맨 위: '모아 보기'(기본) / '한 곳 보기'] --> B{'우리 기준 통과만'(기본) / '전체'}
  B --> C[매물마다 좌표: state.geo 저장값 → 없으면 상세 주소 검색 · 못 찾으면 지역 → 역 위치 = '대략 위치' · Nominatim 1초에 1건]
  C --> D{확대 정도}
  D -->|13 미만| E[구별 동그라미 + 매물 수 · 구 이름은 지역·주소 칸의 'OO구' · 위치는 그 구 매물들의 가운데]
  E -->|누름| F[그 구 매물이 다 보이게 · 좁은 화면도 13 이상으로 확대]
  D -->|13 이상| G[매물 핀 + '이름 · 월 N만원' · 대략 위치 표시]
  G -->|누름 · Enter| H[자세히 보기 시트]
  A --> W[직장 핀 · 있을 때]
  A --> R[오른쪽 목록: 구별 개수·이름 · 위치 찾는 중 · 위치 못 찾음(수정에서 지역·주소)]
  A --> O['한 곳 보기' = 예전 입지 지도(역 걷는 길·직장 도로) 그대로]
```

- 통과 매물이 0곳이면 지도 대신 "'전체'를 누르면…" 안내.
