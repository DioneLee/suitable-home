# 한눈에 비교 · 거래 유형 (v8, 2026-11-03)

실사용 피드백: "실제 월 부담 ○○만원"만 크게 나와 보증금·전세·매매 여부가 안 보였다. 매물마다 계약 조건 · 전입신고 · 주소 · 통근 · 원문 링크를 맨 앞 "한눈에 비교"에 모으고, 점수·추천은 아래 "더 깊이 보기"로 뺀다. 백업: `index_v8_backup.html`.

```mermaid
flowchart TD
  M[migrate: deal 없음 → '월세' · moveIn·floorNo·route·url 없음 → 비움<br/>settings: mortRate 4 · depMax 13000 · priceMax null] --> E[evaluate]
  F[매물 폼: 거래 유형에 따라 금액 칸 이름·보이는 칸이 바뀜<br/>월세: 보증금·월세 / 전세: 전세금 / 매매: 매매가·대출 기간·상환 방식<br/>원문 링크가 바뀌면 urlSaved = 오늘] --> E

  C -- 월세 --> C1[월세 + 관리비 + max 0, 보증금 − 내 돈 × 연이율 ÷ 12]

  C -- 매매 --> C3[관리비 + 주담대 월 상환<br/>이자만: P × r · 원리금균등: P·r ÷ 1 − 1+r^−n<br/>이자 / 원금 따로 기록]
  C1 & C2 & C3 --> R[탈락: 전입신고 불가 · 월세 95만 초과는 월세만<br/>보증금·전세금 상한 depMax 는 월세·전세 · 매매가 상한 priceMax 는 매매]
  R --> T["cond(l): '월세 1억 3,000 / 50 · 관리비 5' · '전세 2억' · '매매 3억 2,500 · 이자 ○만 + 원금 ○만'"]
  T --> G[한눈에 비교: 데스크톱 표(매물 = 열) / 휴대폰 카드 · 지금 집 맨 앞 회색 · 정렬 4종]
  T --> X[조건 표기: 매물 카드 · 시트 · 데스크톱 패널 · 리포트 차트 라벨·결론 · 순위표 · 홈 추천 · 히어로 숫자]

  H[홈 순서: 히어로 → 한눈에 비교 → 더 깊이 보기 · 펼친 상태 최종 추천 · 메뉴 바로가기] --> G
```

- 금액 칸은 하나(`deposit`)를 유형별로 보증금 · 전세금 · 매매가로 쓴다. 전세·매매는 `rent = 0`.
- 매매 원리금균등의 월 부담에는 원금이 들어간다(사용자 결정). 원금은 자산으로 쌓이는 돈이라 금액 옆에 "이자 ○만 + 원금 ○만"으로 나눠 보여준다.
- 보증금 상한은 예전엔 고정 1억 3천이었다 → '자금'의 "보증금·전세금 상한" 칸(기본 13000, 비우면 사용 안 함).
- 원문 링크는 http(s) 만 링크로 만든다. 주소는 네이버지도 검색(`map.naver.com/p/search/…`)을 새 창으로.
